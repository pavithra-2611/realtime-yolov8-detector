# 🔍 Real-Time YOLOv8 Object Detector

This project is a real-time object detection system using **YOLOv8** and **OpenCV**, built with Python. It leverages Ultralytics' YOLOv8 for high-performance and accurate detection on live webcam or video feeds.

## 🚀 Features

- Real-time object detection using YOLOv8
- Webcam or video input support
- Bounding box display with labels and confidence
- Easy to run and extend for other use cases
